## 📖 Overview

**SpoonBoy** is a comprehensive **V2Ray / Xray** project that bundles the most complete **subscription package** together with **optimized, ready‑to‑use settings** for unrestricted and secure internet access. It includes the **v2rayN** Windows client plus curated configs for **sing‑box** and **WireGuard (WARP / WoW)**, so you can connect in minutes without manual setup.

The subscription pack is organized **by country**, **by protocol** (VMess, VLESS, Shadowsocks, Trojan), and **by social network**, with the most comprehensive set of **open ports** to bypass filtering in heavily restricted regions such as Iran and China. Default settings are tuned for **speed and security**, and the lists are **regularly updated** to keep up with changing network conditions.

SpoonBoy is for anyone who needs **free, fast, and private internet** across **Windows, Linux, macOS, iOS, and Android** — whether you want a simple plug‑and‑play setup or raw subscription links and node lists to build your own **v2raycollector**.

> 🔎 **Keywords:** free V2Ray, V2Ray subscription, V2Ray config, Xray core, sing‑box, v2rayN, WireGuard WARP, VMess, VLESS, Shadowsocks, Trojan, free VPN, proxy, bypass filtering, unrestricted internet.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/morpheusadam/SpoonBoy
```

### 2. Open the client

Enter the project folder — the latest subscriptions and VPN configs are ready to use.
On Windows you can launch the bundled **`v2rayN.exe`** client directly.

### 3. Update subscriptions

Copy the links from [`README/SUB-LIST.md`](README/SUB-LIST.md), then in your client go to:

```text
SUBSCRIPTION GROUP → UPDATE SUBSCRIPTION
```

and update to pull the newest servers.

### 4. Country‑specific subscriptions

For gaming/Spotify or country‑limited use, see [`README/CUNITRIES.md`](README/CUNITRIES.md).

### 5. Build your own collector

Use [`README/NODES.md`](README/NODES.md) and [`README/TELEGRAM-CHANELS.md`](README/TELEGRAM-CHANELS.md)
to source nodes and channels for a custom **v2raycollector**.

### 6. Choose a client

Pick the right app for your OS from [`README/CLIENTS.md`](README/CLIENTS.md).
